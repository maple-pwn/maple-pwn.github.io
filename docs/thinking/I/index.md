# 信息时代的我们


## 写在前面

个人与时代，一个好宽广的命题啊,其实很早之前便有一个懵懵懂懂的想法，想要写一些什么，但总是流于心中，迟于笔下，久久难言。最近与鹭师傅产生了一些分歧，这篇文章也算是给我和鹭师傅一个共同的回答吧。一份二十一世纪大学生的思考


## 时代与我们

不可否认，这是一个宏伟的时代，辉煌的时代，人们可以做到千百年来前所未有之事。传统的与新潮的，东方的与西方的，保守的与激进的，无数的思想在互联网上碰撞、传播，无尽的信息充斥网络空间，论战无处不在、阵营林林总总。每个人都或主动或被动，或知情或不知情地被安排了身份，**立场先于观点，动机先于表达**。党同伐异，乐此不疲

这是时代的幸运，任何人都有能力发出自己的声音，尽管微不足道；这也是时代的悲哀，任何人都有能力领导舆论，只要利益所在。

从新闻学来说，存在这样一个“二八定律”，即百分之二十的人发出百分之八十的声音，只要一个呼声所占百分比大于百分之四十，它就可以称为引导舆论的呼声。更加可怕的是，处于后真相时代的我们往往会被有意误导，只需要揭露部分的事实，真相完全可以变得不可控，不可知。

同样，这样一个时代下，真相或许并不重要，平台需要流量，新闻需要热度，它们并不在意真实情况是什么，它们只知道这样说会有更多流量，可以获得更多的现金，仅此而已

这个时代，没有真正的事实，事情总是可以反转再反转，阵营总是可以划分再划分，进而推动网络论战的存在，它可以带来巨大的流量，可以带来巨大的盈利

换成一句悲哀的玩笑话，“赚钱嘛，不磕颤”。

但被舆论引导的我们，该何去何从呢？


## 我们与时代

之前我认为个人在时代之下做不到什么，二八定律存在，让那百分之八十的人仅占有百分之二十的言语权，起不到舆论的领导作用。非常的悲观现实主义

鹭师傅说的很对，倘若都像我这样的想法，那只会让主流舆论愈演愈烈，进而让那些既得利益者得利，让他们为所欲为，想想就很可怕啊

`愿中国青年都摆脱冷气，只是向上走……能做事的做事，能发声的发声。有一分热，发一分光，就令萤火一般，也可以在黑暗里发一点光，不必等候炬火` 我高中时作文很喜欢这句话，如今竟忘却了，可惜可惜，若能做到有一分热发一分光，或许那百分之八十中将出现足以对抗舆论的思想，也或许......我也不知道会发生什么，总之先让它发生下去吧，不会变得更差的

勿忘初心，方得始终。初心是什么，无非是遵循本心，尽我之能，行我之事，问心无愧罢了。我们与时代也就那个样子，无论如何发展，总归是需要人的，既然他们可以肆意引导舆论，我们又为何不能守住舆论道德呢


## 记
