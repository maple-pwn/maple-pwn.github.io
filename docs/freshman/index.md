# 新生电脑开荒指南

按顺序完成这套教程，就能把一台 Windows 11 电脑变成可以学习、写代码和用 AI 协作的电脑。

## 这套教程里的按钮怎么找

- “A → B → C”表示先点击 A，再在打开的菜单或页面中点击 B，最后点击 C，不是把整句话输入搜索框。
- “按 Win”是按键盘上带 Windows 标志的键；“Ctrl+Shift+X”表示按住 Ctrl、Shift，再按 X，然后松开。
- 软件名称后写“左侧”“右上角”，均指该软件窗口内部，不是 Windows 桌面。先把窗口最大化，避免按钮被折叠。
- 搜索扩展用“扩展搜索框”；搜索命令用 `Ctrl+Shift+P` 打开的顶部输入框；执行命令用“终端 → 新建终端”打开的下方区域。三个地方不能混用。
- 如果你的按钮名称不同，先核对自己打开的是哪一个软件、Windows 还是 WSL 窗口，以及是否已经切换中文。找不到就停下，将当前页面标题和能看到的按钮文字发给 AI。

## 先看阅读顺序

1. 先完成 [01 AI IDE](01-ai-ide.md)：没有代理也可以先开始使用 AI。
2. 需要访问特定服务时，再按自己的需要完成 [02 网络工具](02-network-clash-verge.md)。
3. 接着完成 [03 开发环境](03-development/index.md)。
4. 再完成 [04 账号与代码同步](04-accounts-git-github.md)，让代码能保存到 GitHub。
5. 最后阅读 [05 更强的 AI](05-advanced-ai.md)，把 GPT、Claude 和 AI IDE 配合起来。

每一条命令都要在标明的窗口执行。不要一次复制很多命令；执行一条、看见“检查成功”，再做下一条。

## 卡住时怎样向 AI IDE 求助

把下面模板复制到 Qoder、WorkBuddy、GPT 或 Claude，再补上你自己的内容：

~~~text
我正在做《新生电脑开荒指南》第 X 章第 Y 步。
教程链接是：
我执行的是：
当前窗口名称和完整报错文字是：
请一次只告诉我下一步怎么做，并告诉我看到什么算成功。
~~~

不要发送密码、验证码、恢复码、订阅链接、API Key、SSH 私钥或学校内部资料。发截图前，先检查画面中是否出现这些内容。
