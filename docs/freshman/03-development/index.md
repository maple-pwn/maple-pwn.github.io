# 03：开发环境

本章分两条路线。先完成 Windows 下的 VS Code；课程或项目需要 Linux 命令、Docker、服务器环境时，再继续完成 WSL。

## 选择路线

- 只想写 Markdown、Python 入门、网页或普通作业：先做 [Windows 下的 VS Code 生产环境](windows-vscode.md)。
- 需要 Linux 命令、Linux 编译环境或老师要求 Ubuntu：继续做 [WSL + VS Code](wsl-vscode.md)。

Windows 路线依次完成中文界面、C 编译与调试、Python 虚拟环境与依赖安装；项目放在“文档 → code”。WSL 路线项目放在 `~/code`。两个系统各自建立环境，不要复制 Windows 的 `.venv` 到 WSL。

## 完成清单

- [ ] VS Code 已切换中文。
- [ ] C 程序编译运行成功，Python 程序使用项目的虚拟环境运行成功。
- [ ] 至少有一个项目目录。
- [ ] 需要 WSL 的同学已让 VS Code 连接 Ubuntu。
