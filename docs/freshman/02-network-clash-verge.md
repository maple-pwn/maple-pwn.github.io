# 02：网络工具——iKuuu + Clash Verge

本章用 iKuuu 提供的账户订阅和 Clash Verge 客户端配置网络连接。请遵守学校、单位、服务条款和所在地规则；订阅链接等同于账号凭据，不能截图、转发或提交到 GitHub。

## 1. 登录 iKuuu

> 题外话，搜索引擎建议用必应，有梯子之后用谷歌，其他的搜索引擎（如某度）一概不建议

1. 打开 [iKuuu 登录页](https://ikuuu.foo/auth/login)。
2. 注册或登录你自己的账户。
3. 登录后的后台属于个人账户页面，本文未能核实其当前菜单位置，因此不能保证入口一定在左侧或右上角。先阅读后台提供的“使用教程”或“客户端”说明，选择 Windows、Clash 对应的说明，按其中指引找到订阅复制入口；界面不一致时向服务商客服询问“Windows 的 Clash 订阅链接在哪里复制”。
4. 找到订阅地址后，暂时留在页面，不要公开复制到聊天、截图或仓库。

**检查成功：** 账户后台能看到属于你自己的订阅地址或配置入口。

## 2. 安装 Clash Verge

1. 打开 [Clash Verge 官方安装页](https://www.clashverge.dev/install.html#__tabbed_2_1)。
2. 该文档对应 **Clash Verge Rev**。在安装页选择 Windows。先在电脑按 `Win+I` → “系统” → 页面下方“系统信息”，查看“系统类型”：x64 电脑选 x64，ARM64 电脑选对应 ARM64 安装包，不要下载 macOS 或 Linux 版本。
3. 双击安装程序，按提示安装并启动 Clash Verge。
4. Windows 弹出网络或防火墙提示时，确认程序名称是 Clash Verge 后再按提示选择。

**检查成功：** Clash Verge 可以正常打开，左侧能看到“订阅/配置”“代理”等页面。

## 3. 导入订阅

1. 回到 Clash Verge Rev 主窗口，在左侧导航栏点击“订阅”（Profiles）。后面的操作在该订阅页面完成，不是在浏览器地址栏输入。
2. 使用页面中的订阅链接导入区域；如果该版本显示的是“新建”，先点击“新建”，在弹出配置中选择远程订阅（Remote），找到 URL/订阅链接输入框。不同版本界面可对照 [官方订阅导入说明](https://www.clashverge.dev/guide/profile.html)。
3. 回到 iKuuu 后台，复制自己的订阅地址。
4. 点击 Clash Verge 的 URL/订阅链接输入框，按 `Ctrl+V` 粘贴；点击该导入区域的“导入”，或新建窗口的“保存”，等待订阅卡片出现。点击该卡片启用它，再进入左侧“代理”（Proxies）页。
5. 在“代理”页选择“规则”（Rule）模式，展开订阅提供的节点选择组，点击其中一个节点。组名由订阅提供方设置，不一定就叫“节点选择”；若列表为空，回到订阅页检查是否导入成功并启用了刚才的配置。

**检查成功：** 节点列表出现，选择一个节点后状态变为已选择或延迟测试有结果。

如果导入失败：先确认订阅地址没有少字符；再回到 iKuuu 后台重新复制；仍失败时只联系该服务的官方客服，不要把完整订阅地址发给陌生人。

## 4. 开启并检查系统代理

1. 在 Clash Verge Rev 主窗口找到标为 **系统代理（System Proxy）** 的开关并打开。版本之间可能放在首页或设置页：先点左侧“首页”查看；没有时进入左侧“设置”查找同名开关。不要将旁边的 TUN/虚拟网卡开关当作系统代理。
2. 保持 Clash Verge 在运行状态。
3. 打开浏览器访问你需要使用的服务，确认页面能正常加载。
4. 用完后，回到 Clash Verge 关闭 **System Proxy/系统代理**。

**检查成功：** 开启时需要的服务能访问；关闭后 Windows 的网络仍能正常使用。

如果浏览器突然无法联网：先回到 Clash Verge 关闭系统代理；确认网络恢复后，再检查当前节点和订阅更新时间。如果 Clash Verge 已无法打开，按 `Win+I` → “网络和 Internet” → “代理” → “手动设置代理”下的“使用代理服务器” → “设置”，关闭“使用代理服务器”并保存。学校或单位统一管理的代理不要擅自修改，先联系管理员。

本节只检查浏览器访问。浏览器能联网，不代表 WSL、Git 或 uv 的命令已经使用代理；后面若只有终端下载失败，记录终端名称和报错单独排查，不要反复切换所有开关。不要在不了解含义时修改 TUN、系统 DNS 或防火墙规则。官方参考：[Clash Verge Rev 快速入门](https://www.clashverge.dev/guide/quickstart.html)。

## 完成清单

- [ ] 已登录自己的 iKuuu 账户。
- [ ] 已安装 Clash Verge。
- [ ] 已导入自己的订阅，且没有公开订阅地址。
- [ ] 已会开启和关闭系统代理。
