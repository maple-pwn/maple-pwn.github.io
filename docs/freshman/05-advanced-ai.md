# 05：更强的 AI——GPT、Claude 与 AI IDE 协作

本章不要求购买任何订阅。先用自己的账户页面实际可见的功能；是否需要验证、付费或服务是否可用，均以产品页面为准。

## 1. 打开 ChatGPT

1. 打开 [ChatGPT](https://chatgpt.com/)。
2. 如果页面允许直接试用，可以先提一个简单问题；要保存聊天记录时，按页面提示注册或登录。
3. 点击 **New Chat/新建聊天**。
4. 发出下面提示：

~~~text
我是计算机新生。请用一步一做的方式带我完成任务。
每次只给一个操作；先告诉我应该点击哪里或输入什么，再告诉我看到什么算成功。
不要要求我发送密码、验证码、私钥或订阅链接。
~~~

**检查成功：** 你能新建并保存一段聊天记录。

官方说明：[ChatGPT 首页与新建对话](https://help.openai.com/en/articles/9125172-the-chatgpt-home-page)。

## 2. 打开 Claude

1. 打开 [Claude](https://claude.ai/)。
2. 按页面要求注册或登录。
3. 新建对话，发送与上一节相同的提示词。
4. 如果页面显示地区、资格、付款或验证限制，按页面指引处理；不要使用来路不明的账号或脚本。

**检查成功：** 你可以在 Claude 中创建一个普通对话并得到回复。

## 3. 把教程链接交给 AI

先在浏览器打开教程文章，按 `Ctrl+L` 选中地址栏 → `Ctrl+C` 复制链接。切换到 ChatGPT 或 Claude 的对话页面，点击页面下方的消息输入框（新对话时也可能位于页面中央），粘贴下面模板并补齐内容，再点击输入框旁的发送按钮。不要把模板粘贴到浏览器地址栏，也不要粘贴到 VS Code 终端执行：

~~~text
教程链接：<粘贴这一篇文章的链接>
我正在做第 X 步，目标是：<一句话>
我输入的命令/点击路径是：<完整内容>
我看到的完整报错是：<完整内容>
请判断我现在是否应该继续。若不该继续，只给一个下一步，并告诉我成功标志。
~~~

如果 AI 无法读取链接，在文章里用鼠标选中当前小节 → `Ctrl+C`，回到聊天输入框 → `Ctrl+V`，把步骤原文一并发出。复制 VS Code 报错时，在下方终端中用鼠标选中从执行命令到错误结束的文字，再按 `Ctrl+Shift+C` 复制；不要只发送最后一个词。

AI 回答命令时，先看三件事：命令会改哪些文件、是否要求管理员权限、是否会删除或上传资料。不确定时把命令原样发回 AI，要求解释每个参数。

## 4. AI IDE 与聊天 AI 怎样分工

- **Qoder/WorkBuddy：** 打开项目后创建、修改、检查项目文件。
- **ChatGPT/Claude：** 解释教程、比较方案、读报错、帮你检查计划。
- **你自己：** 决定是否执行、检查改动、保存代码、保管账号与密码。

推荐顺序：先让 ChatGPT 或 Claude 把任务拆成一小步；再在 Qoder 或 WorkBuddy 执行这一小步；最后在终端用 `git diff` 或程序运行结果检查。

## 5. 必须不发给 AI 的内容

不要上传：密码、验证码、恢复码、身份证件、银行卡信息、SSH 私钥、API Key、网络订阅链接、未公开作业答案、学校或单位的内部资料。

如果文件夹里可能有这些内容，先不要把整个文件夹交给 AI IDE；只新建一个干净的练习文件夹。
