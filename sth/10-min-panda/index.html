10 minutes to pandas

导入

import numpy as np
import pandas as pd

pandas中的基本数据结构

pandas提供了两种处理数据的类

  • Series：一个一维带标签的数组，可以容纳任何类型的数据

如整数、字符串、Python对象等

  • DataFrame：一种二维数据结构，可以像二维数组或具有行和列的表格一样存储数据

对象创建

通过传递一个值的列表来创建一个 Series，让 pandas 创建一个默认的 RangeIndex

In[3]: s = pd.Series([1, 3, 5, np.nan, 6, 8])

In[4]: s
Out[4]:

1   3.0
2   5.0

4   6.0

选择

Note

虽然标准 Python / NumPy 表达式用于选择和设置很直观，在交互式工作中很方便，但对于生产代码，推荐使用优化的 pandas 数据访问方法， DataFrame.at() 、 DataFrame.iat() 、 DataFrame.loc() 和 DataFrame.iloc() 。

Getitem([])

对于 DataFrame ，传递单个标签会选择一列并返回 Series ：

In [24]: df["A"]
Out[24]: 
2013-01-01    0.469112
2013-01-02    1.212112
2013-01-03   -0.861849
2013-01-04    0.721555
2013-01-05   -0.424972
2013-01-06   -0.673690
Freq: D, Name: A, dtype: float64

如果标签只包含字母、数字和下划线，你也可以使用列名属性：

In [25]: df.A
Out[25]: 
2013-01-01    0.469112
2013-01-02    1.212112
2013-01-03   -0.861849
2013-01-04    0.721555
2013-01-05   -0.424972
2013-01-06   -0.673690
Freq: D, Name: A, dtype: float64

传递一个列标签列表可以选择多个列，这对于获取子集/重新排列很有用：

In [26]: df[["B", "A"]]
Out[26]: 
                   B         A
2013-01-01 -0.282863  0.469112
2013-01-02 -0.173215  1.212112
2013-01-03 -2.104569 -0.861849
2013-01-04 -0.706771  0.721555
2013-01-05  0.567020 -0.424972
2013-01-06  0.113648 -0.673690

对于 DataFrame ，传递一个切片 : 可以选择匹配的行：

In [27]: df[0:3]
Out[27]:

缺失数据

对于 NumPy 数据类型， np.nan 表示缺失数据。默认情况下，它不包含在计算中。参见缺失数据部分。

重新索引允许更改/添加/删除指定轴上的索引。这将返回数据的副本：

In [57]: df1 = df.reindex(index=dates[0:4], columns=list(df.columns) + ["E"])

In [58]: df1.loc[dates[0] : dates[1], "E"] = 1

In [59]: df1
Out[59]: 
                   A         B         C    D    F    E

2013-01-03 -0.861849 -2.104569 -0.494929  5.0  2.0  NaN
2013-01-04  0.721555 -0.706771 -1.039575  5.0  3.0  NaN

DataFrame.dropna() 删除包含缺失数据的任何行：
